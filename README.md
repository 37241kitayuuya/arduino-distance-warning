# Arduinoを使用した距離警告システム

## 概要

Arduinoと超音波センサーを使用して障害物との距離を測定し、
距離に応じてLEDとブザーで警告するプログラムを作成しました。

## きっかけ

学校の授業でArduinoを使ったプログラミングを学んだことをきっかけに、
センサーから取得した情報をプログラムで処理し、
実際の機器を動かすことに興味を持ちました。

そこで、超音波センサーを使って障害物との距離を測定し、
距離に応じてLEDとブザーの動作を変化させるプログラムを
自分で調べながら作成しました。

## 試したこと

以下のような処理を実装しました。

- Arduinoと超音波センサーを使用して障害物との距離を測定
- 距離を3回測定し、平均値を計算して距離の変化を確認
- シリアルモニターに測定した距離を表示
- `if`文を使用して距離に応じた条件分岐
- 20cm以下を注意ゾーンとしてLEDを点灯し、ブザーで警告
- 10cm以下を危険ゾーンとしてLEDを点滅させ、ブザーで警告
- `for`文を使用してLEDを指定回数点滅
- 距離測定やLEDの点滅処理を関数に分けて実装

## 試行錯誤したこと

最初は、超音波センサーを使ってどのように距離を測定するのか
分からなかったため、インターネットやAI、参考資料を用いて調べながら
プログラムを作成しました。

また、プログラムを作成する中でif文やfor文の書き方などに
間違いがあり、エラーが発生することもありました。

エラーが発生した場合は、コードを確認して原因を調べ、
修正した後にArduinoへプログラムを書き込んで実際の動作を確認しました。

さらに、障害物との距離によってLEDやブザーの動作を変えるため、
どの距離を条件として設定するかを試しながら調整しました。

## 最終的にできたこと

超音波センサーで障害物との距離を測定し、
その距離に応じて「安全」「注意」「危険」の3段階に分けて
LEDとブザーで警告するプログラムを作成しました。

また、距離を1回だけ測定するのではなく、3回測定して平均値を
計算することで、測定値を安定させる処理も試しました。

距離の測定処理やLEDの点滅処理はそれぞれ関数として分け、
プログラムを整理して書くことも意識しました。

## 効果・学んだこと

作業時間を短縮するような直接的な効果はありませんでしたが、
センサーから取得した情報をプログラムで処理し、
その結果に応じてLEDやブザーなどの機器を動作させる

また、分からないことやエラーが発生した際には、まず自分で調べて原因を確認し、
それでも分からない場合は友人に相談してアドバイスをもらいながら、
実際にプログラムを修正して動作を確認しました。

実際に動かして問題を確認し、自分で調べたり周囲に相談したりしながら
改善していくことが重要だと学びました。
